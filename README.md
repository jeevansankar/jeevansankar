### 01. TrustVault — Secure Document Management & Sharing Platform

**Full-Stack Application | Security-Focused Project**

TrustVault is a document management and sharing platform built to provide controlled access to uploaded documents. It allows users to upload, organize, download and share documents with permission-based access.

**Problem Statement**

Traditional document-sharing approaches can make it difficult to manage ownership and control who can access sensitive files. TrustVault addresses this through authentication, document-level permissions and security-focused backend checks.

**Key Features & Implementation**

- Developed a full-stack application using React, Java Spring Boot and MySQL.
- Implemented JWT-based authentication for API access.
- Designed role-aware access for administrators, document owners and viewers.
- Developed document upload, listing, download and deletion functionality.
- Implemented document-level READ and EDIT permission handling.
- Enabled document owners to grant and revoke access.
- Organized backend responsibilities using Controller, Service and Repository layers.
- Implemented email and phone OTP verification as part of account activation.
- Worked on uploaded-file validation and private file-storage handling.
- Added SHA-256 file-integrity support and security-related audit activity logging.
- Focused on preventing unauthorized access to other users' documents.

**Technology Stack**

`React` `Java` `Spring Boot` `Spring Security` `JWT` `MySQL` `Spring Data JPA` `Hibernate` `Docker` `AWS`

**Project Links**

- 🌐 **Live Application:** https://trustvault-app-k8a4.onrender.com
- ⚙️ **Backend API:** https://trustvault-api.duckdns.org
