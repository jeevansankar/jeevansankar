01. TrustVault — Secure Document Management & Sharing Platform

Full-Stack Development | Security-Focused Application

TrustVault is a secure document management and sharing platform that allows users to upload, organize, access and share documents with controlled permissions.

Problem Statement

Traditional document-sharing approaches can make it difficult to control who can access sensitive files. Users need a platform where document ownership, access permissions, authentication and activity tracking are handled systematically.

Solution & My Implementation

- Developed a full-stack application using React, Java Spring Boot and MySQL.
- Implemented JWT-based authentication for secure API access.
- Designed role-aware access for administrators, document owners and viewers.
- Developed document upload, listing, download and deletion functionality.
- Implemented document-level READ and EDIT permission concepts.
- Enabled owners to grant and revoke access to documents.
- Organized backend responsibilities using Controller, Service and Repository layers.
- Implemented email and phone OTP verification as part of account activation.
- Worked on uploaded-file validation and private file-storage handling.
- Added SHA-256 file-integrity support and security-related audit activity logging.
- Focused on ensuring that users cannot access other users' documents without appropriate permissions.

Architecture

Layer| Technology / Responsibility

Backend| Java, Spring Boot

04. Secure REST API Architecture — JWT Authentication & Request-Level Security

Backend Security | Spring Security | JWT | REST APIs

A backend security-focused implementation and learning project exploring how to protect REST APIs and validate access to protected resources.

Problem Statement

APIs must not trust incoming requests automatically. Each protected request needs appropriate authentication and authorization checks. Applications must also handle cross-origin browser access and session behaviour correctly.

What I Designed & Explored

- Designed RESTful API endpoints and backend application layers.
- Worked with Spring Security configuration and security filter-chain concepts.
- Explored JWT generation, validation and authentication workflows.
- Worked on validating authentication tokens on incoming protected requests.
- Configured endpoint access rules for authenticated and unauthenticated requests.
- Explored authorization rules for controlling access to protected resources.
- Studied and configured CORS for cross-origin browser communication.
- Compared stateful session-based authentication with stateless JWT-based authentication.
- Worked with stateless session-management configuration for REST APIs.
- Explored form-based login and JWT-based authentication approaches.
- Tested authentication and API responses using Postman.

Security Concepts

Concept| Purpose
Authentication| Establishing the identity of a requester
Authorization| Determining what an authenticated user can access
JWT| Carrying signed authentication claims
Security Filter Chain| Processing security checks for incoming requests
CORS| Controlling permitted cross-origin browser requests
Stateful Sessions| Maintaining server-side session state
Stateless APIs| Avoiding server-side HTTP session state for authentication
Form Login| Browser-oriented username/password login workflow

Technology Stack: Java · Spring Boot · Spring Security · JWT · REST APIs · CORS · HTTP · Postman

Key Engineering Concepts: Secure request processing, token validation, authentication versus authorization, session management and API protection.
